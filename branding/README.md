# HealthHub brand

## The logo

"HealthHub" has two capital H's. In the logo they share one stem: a white H for health and an amber H for
the hub, locked together in the middle. Two things becoming one is what the app does: it joins patients,
doctors, hospitals and pharmacies around one record.

| File | Use |

## Colors

| Name | Hex | Use |
|---|---|---|
| Navy | `#1B1F3B` | headings, the tile, hero headers |
| Amber | `#FFC53D` | the second H, highlights, primary call to action on navy |

| Red | `#E5484D` | errors, cancel |

## Type

Instrument Sans Bold for the wordmark. The apps use Instrument Sans for headings where it is available
and the system font for body text.
